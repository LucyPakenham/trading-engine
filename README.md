# Algorithmic Trading Engine with Risk Analytics

A Python-based algorithmic trading engine built over 8 weeks, featuring:
- Historical data fetching and analysis
- Moving average crossover strategy
- Backtesting engine with transaction costs
- Risk metrics: Sharpe ratio, VaR, Max Drawdown
- C++ performance core wrapped with Python bindings
- Interactive Streamlit dashboard

**Built with:** Python, C++, pandas, numpy, matplotlib, yfinance, pybind11, Streamlit
